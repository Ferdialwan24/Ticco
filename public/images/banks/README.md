# Panduan Upload Foto Logo Bank & Dompet

Folder ini disiapkan khusus untuk file foto logo resmi. Sistem aplikasi otomatis membaca dan menampilkan foto yang ditaruh di folder ini.

### Lokasi Folder:
`d:\CODE\Ticco\public\images\banks\` (atau path web: `/images/banks/`)

---

### Tips:
- Gunakan file dengan format **PNG transparan** atau **SVG** dengan rasio **persegi panjang / landscape (~16:9 atau 2:1)** sesuai format logo resmi bank.
- Cukup taruh file dengan nama di atas ke dalam folder ini. Aplikasi langsung menampilkan foto tersebut tanpa perlu restart server.
- Jika file belum ditaruh, aplikasi akan secara otomatis menampilkan lencana placeholder persegi panjang bergradasi warna resmi masing-masing bank tanpa gambar rusak.
